# GAL Publicidad

Página web de GAL Publicidad. Es un sitio sencillo: 3 archivos y una carpeta.

| Archivo | Qué tiene |
|---|---|
| `index.html` | Los textos y las secciones de la página |
| `styles.css` | Colores, letras y acomodo |
| `main.js` | Las animaciones (con GSAP) |
| `vendor/` | La librería GSAP, guardada aquí para no depender de otros servidores |

## Datos que hay que cambiar

En `index.html` busca la palabra `CAMBIAR`. Ahí van:

- Número de WhatsApp (aparece 3 veces como `520000000000`)
- Teléfono y correo
- Ciudad

## Cómo verla en tu computadora

Abre `index.html` con doble clic en Chrome.

## Publicarla

Se puede subir gratis a Netlify arrastrando la carpeta completa a https://app.netlify.com/drop
